# Boundary and bulk memory from a nonlocal spin symmetry

## Main claim and its domain

For an open spin-$`\tfrac12`$ chain and finite real $`q\ge1`$, use the symmetric coproduct
```math
E_L=\sum_i\left(\prod_{j\lt i}q^{-Z_j/2}\right)s_i^+
              \left(\prod_{j>i}q^{Z_j/2}\right),\quad
F_L=E_L^\dagger,\quad K_L=q^{\sum_jZ_j/2},\quad
s_i^+=(X_i+iY_i)/2.
```
Let $`\mathcal A_q`$ be the unital *-algebra generated by $`E,F,K`$, including all
products. At $`q=1`$ the usual spin algebra is understood. Projection and norms use
the physical Hilbert space and ordinary infinite-temperature trace, **not a
quantum-dimension-weighted trace**.

Define
```math
M_{L,i}(q)=2^{-L}\|\Pi_q(X_i)\|_{\rm HS}^2,
\qquad C_i(t)=2^{-L}\mathrm{Tr}[X_i(t)X_i],\quad C_i(0)=1.
```

For every symmetry-preserving Hamiltonian, the finite-size infinite-time average
satisfies $`\bar C_i\ge M_{L,i}`$. This projection principle is inherited.
The full symmetry need not exhaust the commutant of a particular Hamiltonian.
[PLATEAU_DICTIONARY](PLATEAU_DICTIONARY.md) identifies the exact excess.

## 1. Finite-size expression

For $`h`$ of the appropriate parity,
```math
\mathcal H_L=\bigoplus_h\mathcal V_{h/2}\otimes\mathbb C^{m_{L,h}},\quad
m_{L,h}=\binom L{(L-h)/2}-\binom L{(L-h)/2-1}.
```
Hence
```math
M_{L,i}=2^{-L}\sum_h\frac{
\|\mathrm{Tr}_{m_{L,h}}(P_hX_iP_h)\|_{\rm HS}^2}{m_{L,h}}.
```
The $`q`$-Clebsch--Gordan recursion evaluates this sum in $`O(L^3)`$ arithmetic work and
$`O(L^2)`$ stored entries for a fixed $`i`$. These counts refer to arithmetic
operations and storage. The image algebra has dimension $`\binom{L+3}{3}`$.

## 2. Edge and fixed-distance limits

For every fixed finite $`q>1`$,
```math
\boxed{M_{L,1}=M_{L,L}=
\frac{\tanh(\log q)}{\sqrt{2\pi L}}+O_q(L^{-1}).}
```
For each fixed integer $`d\ge0`$,
```math
M_{L,L-d}=B_d(q)L^{-1/2}+o(L^{-1/2}),\quad
B_d(q)=\frac{(1-z)^2}{\sqrt{2\pi}}\|J_q^df\|^2,
```
where $`z=q^{-2}`$, $`f_r=q^{-r}\sqrt{1-z^{r+1}}`$, and
```math
(J_q)_{r,r+1}=\tfrac12\sqrt{(1-z^{r+1})(1-z^{r+2})},\quad
(J_q)_{r,r}=\tfrac12(q^{-1}+q^{-3})z^r.
```
All $`B_d`$ are positive. At $`q=1`$, $`M=1/L`$ at every site exactly. The fixed-$`q`$ edge
expansion is not uniform at $`q=1`$.

## 3. Bulk limit with explicit sufficient hypothesis

Put
```math
b(q)=\frac{q^{-1}+q^{-3}}{(1-q^{-2})^2},\quad
q_0=2.0810189966245356\ldots.
```
For fixed $`q`$ with $`b(q)\lt 1`$ (equivalently $`q>q_0`$), and $`i_L/L`$ tending to $`x\in(0,1)`$,
```math
\boxed{M_{L,i_L}(q)=\mathcal K(q)\mathcal F(x)L^{-2}[1+o(1)].}
```
The threshold is a sufficient domination criterion, not a phase boundary.
The stated domain includes $`q=2.6`$.

With $`(a;z)_\infty=\prod_{k\ge0}(1-az^k)`$,
```math
A_\pm(q)=(1\mp q^{-1})
 \left[\frac{(z;z)_\infty}{(\pm q^{-1};z)_\infty}\right]^4,
\qquad\mathcal K=\tfrac12(A_+^2+A_-^2),
```
where the lower sign means $`1+q^{-1}`$ and $`(-q^{-1};z)_\infty`$. Explicitly,
$`A_-=(1+q^{-1})[(z;z)_\infty/(-q^{-1};z)_\infty]^4`$.

```math
\mathcal F(x)=\frac{3\sqrt2}{4\pi[x(1-x)]^3}
\int_0^1\frac{u^2(1-u)^2\,du}
 {[\tfrac12+(u-x)^2/(x(1-x))]^{5/2}}.
```
The profile $`\mathcal F`$ is symmetric and positive. Its normalization is fixed by this
integral, not an unknown amplitude. At $`q=2.6`$,
$`\mathcal K=3.60512146027929\ldots`$ and
$`\mathcal K\mathcal F(1/2)=9.55570977050275\ldots`$.

For each fixed $`q>1`$, the iterated boundary-distance limit is
```math
B_d(q)\sim\mathcal K(q)(\pi\sqrt2)^{-1}d^{-3/2}\quad(d\to\infty).
```
One first takes $`L`$ to infinity at fixed $`d`$. This is not a uniform finite-$`L`$
interpolation between the end and a site proportional to $`L`$.

### Corollary: edge-to-bulk contrast

For every fixed finite $`q>q_0`$ and site sequence $`i_L/L\to x\in(0,1)`$,

```math
\frac{M_{L,1}(q)}{M_{L,i_L}(q)}
=\frac{\tanh(\log q)}{\sqrt{2\pi}\,\mathcal K(q)\mathcal F(x)}
L^{3/2}[1+o(1)].
```

**Proof.** At fixed $`q>1`$, $`0\lt z=q^{-2}\lt 1`$. Every factor in the
products defining $`A_\pm`$ is positive, and its deviation from one is
absolutely summable. The products therefore have finite nonzero limits,
so $`0\lt\mathcal K(q)\lt\infty`$. For fixed interior $`x`$, the integral
defining $`\mathcal F(x)`$ is finite and strictly positive: its denominator
is bounded away from zero and its numerator is positive for $`0\lt u\lt1`$.
Write $`a(q)=\tanh(\log q)/\sqrt{2\pi}>0`$. The edge formula becomes
$`a(q)L^{-1/2}[1+O_q(L^{-1/2})]`$; dividing it by the bulk formula proves
the result. This uses the common domain $`q>q_0`$.

For even $`L`$, take the center site $`i_L=L/2`$ and $`x=1/2`$. The coefficient
is $`a(q)/[\mathcal K(q)\mathcal F(1/2)]`$, with the exact value

```math
\mathcal F(1/2)=\frac{2\sqrt3+3\sqrt2\,\mathrm{arsinh}\,\sqrt2}{\pi}.
```

At $`q=2.6`$ this coefficient is $`0.0309890224956737\ldots`$, evaluated from
the analytical products and center value above. Either central site of an
even chain has the same memory by reflection.

Comparison with the exact undeformed value $`M_{L,i}(1)=1/L`$ gives

```math
\begin{aligned}
\frac{M_{L,1}(q)}{M_{L,1}(1)}
&\sim\frac{\tanh(\log q)}{\sqrt{2\pi}}\sqrt L
&&\quad(q>1),\\
\frac{M_{L,i_L}(q)}{M_{L,i_L}(1)}
&\sim\frac{\mathcal K(q)\mathcal F(x)}L
&&\quad(q>q_0).
\end{aligned}
```

Each statement fixes finite $`q`$; each bulk comparison also fixes the limiting
interior fraction. The [physical mechanism](PHYSICAL_MECHANISM.md) explains
the contrast through local overlaps and its retained-polarization readout.

## 5. Where the memory is an actual plateau

Let $`R_j`$ be the local Hecke matrix, with eigenvalues $`q`$ and $`-q^{-1}`$. Set
```math
P_j=(qI-R_j)/(q+q^{-1}),\quad U_j=I-2P_j,\quad
\mathcal L^\dagger(O)=\sum_j\gamma_j(U_jOU_j-O),\quad\gamma_j>0.
```
The unrecorded local random kicks define a unital self-adjoint Markovian model.
Its Dirichlet form is a sum of squared commutators. Its zero space is precisely
the commutant of all $`R_j`$, namely $`\mathcal A_q`$ in this representation. Thus its long-time
operator map is $`\Pi_q`$ and its local correlation tends to $`M`$ exactly. The general
stationary-space method is inherited from open-system commutant theory.

convergence to a coherent Hamiltonian preserving the full algebra and gives
